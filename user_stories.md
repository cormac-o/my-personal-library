User Stories will be archived when they are fulfilled, this is a living document of a kind of backlog of stories to be completed.


==================
Step 1 - User Auth
==================

MVP Features:
Register User, Login/Logout, view user details, update user details, delete user details.

- As a user, I want to register so I can access the app.
- As a user, I want to view my profile details so I can ensure they are correct.
- As a user, I want to update my details so they stay correct.
- As a user, I want to delete my account so that my personal details are removed.
- As a user, I want to login with a password so that my details are protected.
- As a user, I want to logout so that my details cannot be accessed when I am not using the app.
